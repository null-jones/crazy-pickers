QA harness

Runs each picker at 1280×720 with a throwaway roster, grabs a frame every second from GO until the result banner, and reports console errors, run length and the worst frame hitch. Needs python3 serve.py; contact sheets land in qa/ (git-ignored). Add ?shim=1 if the page is in a background tab or an embedded pane that throttles requestAnimationFrame. ?only=car-crash,foul-ball limits the run; ?names=20 uses twenty names.
